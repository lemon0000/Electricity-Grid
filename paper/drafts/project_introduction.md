# 智算中心达产过程中的分阶段接入与柔性可交付性研究

更新日期：2026-10-22。研究方案与现有进展。

## 1 这个项目研究什么

本项目面向逐步达产的AI智算中心，研究业务增长、计算设备分批投运与电网扩建进度不一致时，业务柔性能否支撑给定的分阶段接入方案，并识别任务恢复和小时级清洁电力要求对履约能力的限制。

智算中心从建成到满负荷运营，需要经历业务逐步增长和设备分批投运的过程。支撑接入的线路、主变等电网工程也有自己的建设工期。三种进度可能不同步：设备已经可用、业务已经到达，电网扩建却尚未完成；也可能电网已经具备供电条件，业务或设备仍处于爬坡阶段。本研究把这些进度分别表示，用相同的业务服务要求比较不同接入方案。

业务柔性指在任务允许的期限内，调整一部分计算的执行时间。例如，电网紧张时暂缓部分计算，待供电条件改善后补做。这可以缓解当前小时的取电压力，但任务并没有消失。后续必须具备空闲计算设备、供电空间和满足匹配要求的清洁电量，才能在截止时间前完成补做。

因此，分阶段接入能否成立，既取决于当前能降低多少负荷，也取决于之后能否完成任务。随着业务达产，如果新增业务占用设备的速度快于设备投运，恢复空间可能收紧；如果设备同步增加，这种收紧也可能减弱。早期阶段是否更灵活，需要由业务和设备两条路径共同判断。

本研究以固定接入点和少量给定的建设、接入计划为对象，评估每项计划在哪些阶段可以履约、在哪些阶段出现缺口，以及限制来自哪里。

## 2 几个基本概念

| 概念 | 本研究中的含义 |
|---|---|
| 业务达产 | 计算任务需求逐步接近目标运营规模。需求由外部路径给定，不能为了让方案可行而减少。 |
| 设备投运 | 计算模块完成安装与调试，开始提供可执行计算能力K。尚未投运的设备不能用于补做任务。 |
| 分阶段接入 | 随实际建成的设备与电网条件，逐期释放接入额度。给定方案可以包含保供额度F和附带调用条件的额度X。 |
| 业务柔性 | 在任务规则允许的范围内推迟计算，并在原截止时间前完成的能力。 |
| 恢复债务 | 已推迟但尚未完成的计算工作量，需要按任务产生时间及截止时间持续记录。 |
| 小时级CFE匹配 | 每小时用电的目标份额，与同小时、适用地域内可归属的无碳发电量匹配。 |
| 可交付性 | 在声明的网络范围、服务规则和信息条件下，响应、清洁电力匹配及任务完成能否共同兑现。 |

CFE是carbon-free energy，包含的电源范围由核算规则确定。它是电量归属核算，不追踪物理电子。例如，某小时实际用电100MWh、匹配目标80%，就需要该小时适用范围内80MWh可归属的无碳电量。补做任务增加的用电也要计入。

## 3 研究要回答的三个问题

第一，业务快慢达产、设备分批投运与电网按期或延期投运的不同组合，会使给定接入方案在哪个阶段遇到履约瓶颈？研究需要区分业务尚未到达、设备能力不足、电网供电受限和任务恢复受限。

第二，同样的即时可调功率，在不同达产阶段是否仍代表相同的履约能力？重点检查瓶颈何时来自当期可延期任务不足，何时来自截止时间前的设备、供电或清洁电量不足，以及小时级CFE目标如何改变这些边界。

第三，只按瞬时MW或固定恢复余量评价，是否会改变对给定分阶段接入方案的判断？将这些简化评价与完整时序评价对照，检查是否出现阶段性通过与不通过的差异，以及方案优劣判断是否改变。

## 4 怎么开展研究

### 4.1 分别给定三条进度路径

慢时间尺度描述业务需求、设备投运和电网工程状态。初步采用两至三期设备投运、一个候选电网工程，以及少量固定的接入额度计划。业务快慢达产与电网按期或延期投运交叉形成机制情景；设备投运路径单独给定，保持安装、在建和可用状态的一致性。

实际建成网络约束当期可释放和可交付的接入额度；已投运设备K约束实际业务执行和补做。未完工的工程不提供新增能力，未来投运不能追认过去已经发生的服务缺口。F与X沿用既有合同含义：正常状态检查完整F+X，声明的故障状态检查F及X允许的条件调用。业务柔性容量D与接入额度X分别报告；设备、业务和接入之间的对应关系需要通过明确的映射与网络检查建立。

### 4.2 逐小时追踪执行、延期和补做

运行层记录任务到达、当期执行、延期和恢复。q表示当期推迟的功率等效工作，r表示补做消耗的功率，二者共享双向业务调节容量D，满足：

**q+r≤D。**

q还受当期可延期任务比例约束；r还受已投运设备的剩余能力、任务适配、补做效率和供电条件约束。在统一的功率等效口径下，若基准任务占用为w，当期执行与补做合计须满足w-q+r≤K；已经由q释放的空间只计算一次。恢复债务按效率核减，任务到期后的补做不能消除已经发生的逾期。

上述K约束采用功率等效的计算资源口径，K与计量点总取电P分别定义。设备能力、工作量和取电功率之间的映射需要先核定。主实验拟将已投运设备的待机功耗、任务执行及配套耗能纳入实际取电闭环，因此增加K也可能增加用电负担。相关映射属于待完成的模型衔接，现有归一化小例子不代替实际设备参数。

### 4.3 同时检查网络与小时清洁电力

不同建设状态下，重新计算网络可用能力、所需削减和恢复时的供电空间。电网响应规则保持一致，调用量可以随实际网络与负荷状态变化，不能对所有建设方案沿用一条固定调用序列。

主实验拟按实际取电核算清洁匹配，将补做和待机用电计入P，并与设备映射一同核验。比较方案使用相同的外部清洁资源路径及归属规则；若发生电量分配，须守恒且避免重复归属。不能让方案通过自身削减，凭空增加可归属清洁资源。目标比例为α、实际小时用电为P、可归属电量为Y时，检查αP≤Y。

两类服务如何记账也须固定。现有运行研究采用一个特定比较合同：电网与CFE分别承诺的削减量需要共同兑现，并在一份任务、容量和恢复资源内执行。本研究先在这一明确规则下评价；它是否适用于具体项目，需要独立的合同与计量依据。同一次削减能否同时计入两项服务，会改变要求，不能在不同方案之间切换。

### 4.4 保持信息与时间连续

给定建设计划在评价前确定；运行策略只能使用当时已经观察到的信息。具有相同观测历史的路径采用相同动作，不能根据事后知道的清洁高峰或工程延期安排恢复。

连续时段之间传递任务债务、预算与运行状态。若选用相隔较远的阶段运行窗口，各窗口必须具有明确前史并覆盖任务期限所需的后续观察；不能跳过中间时段后直接接上债务，也不能把债务自动清零。连续跨阶段运行则在真实相邻小时衔接。

## 5 实验怎样比较

主实验围绕少量给定计划开展。每项计划使用相同的外生业务需求、任务期限、清洁资源和评价标准；设备或电网投运时点的不同作为计划本身的差异保留。先完成小规模端到端验证和整条计算路径的资源测量，再固定主实验规模。

| 比较内容 | 需要判断的问题 |
|---|---|
| 业务快慢达产×电网按期或延期 | 进度错位在哪一阶段形成约束，设备投运能否提供相应能力？ |
| 瞬时MW评价、固定恢复余量、完整时序评价 | 忽略恢复空间和截止时间，是否改变对同一接入计划的判断？ |
| 可延期比例、任务期限、小时CFE目标的少量变化 | 方案判断改变的边界在哪里，主要机制是否稳定？ |
| 固定建设计划和运行策略，在独立留出路径上执行 | 选定方案能否继续满足响应、CFE及任务完成要求？ |

运行层保留仅电网、仅CFE、联合共享资源和分账规划四类诊断，用来解释两类服务的作用。主实验的阶段组合及参数点将在端到端小例验证后单独确定；已有1,900个参数单元及其结果按原定义保留。

留出评价使用未参与方案选择的路径，不重新优化给定建设计划，按当时可见信息执行冻结的运行策略。结果分别报告各阶段的接入额度、已投运能力、业务占用、恢复余量、网络与CFE缺口、任务逾期及未完成工作。一次策略成功，只支持该策略在已验证场景中的表现；一次算法失败，不等于所有策略都不可行。最低柔性容量只有在上下界证据充分时才报告点值，否则保留区间或未知。

RTS-GMLC电网、Alibaba工作负荷和Google功率资料可作为现有公开数据基础。它们经过假设配对，不是同一地点同时发生的联合观测。阶段路径、设备功耗、任务期限和清洁归属分别标注来源或机制假设；合成情景的等权比较不解释为真实达产率、延期率或违约概率。

## 6 已有基础和待完成工作

已有基础包括分阶段F/X、电网候选工程与非预见性模型规格，选定故障集合下的DC运行基准，以及任务延期、恢复债务和小时CFE的运行代码。逐小时联动已完成一至三小时合成用例及保存后重放检查。这些属于开发验证，尚未形成正式接入容量或服务风险结论。

一个已精确核验的六小时构造例说明了恢复时序的作用：两份各0.1的延期工作，在清洁恢复额度总量与峰值相同时，仅改变额度到达时间，最低双向调节容量可由0.1变为0.2。附加例中，基准业务占用0.2，已投运能力K从0.3提高到0.4，可以使其中一个原本恢复空间不足的情形完成任务。这是归一化机制证据，没有包含设备待机、工程工期或投资优化，不能据此给出实际建设建议。

旧运行研究的1,900个参数单元中，1,856个CFE相关单元被同一个小时的局部必要条件排除，原因是可延期业务份额不足。这是局部算术检查，并未确认所选输入组合都能实际进入相应的电网和参考运行状态；它不是1,856次实际运行失败，也不是当前分阶段方案的实验结果。其余44个仅为未被该条件排除，仅电网方案仍未判定。该结果提示，应先明确清洁资源和业务映射，再分析恢复机制，保留原有负结果。

待完成的核心工作是把三条进度路径与运行层衔接，核定设备—任务—用电映射，完成小案例及独立核验，再开展有界的阶段方案比较。完整168小时登记、最多24小时后续观察的既有执行链，其资源预算和运行验收仍未闭合；新的阶段实验需另行固定设计和预算。当前没有完整正式容量前沿、经验违约概率或工程安全认证。

## 7 与已有研究的关系和预期贡献

任务移峰、业务恢复、小时级清洁匹配与建设规划均有直接前人基础。Fan和Zhao已连接任务队列与电网服务容量承诺［DC14］；Khanal等已在容量扩展中考虑柔性补做和事件约束［DC15］；Riepin等已研究面向清洁计算的时空移峰［CFE05］。Shao等已有数据中心与电力系统长期联合投资［DC17］，Zhu等已有输电建设与跨中心任务迁移［DC19］，Butt等已连接现场资源、任务期限与最小接入容量［DC22］。

本研究拟检验的具体问题是：**在同一固定接入点，业务达产与两侧投运进度的错位，是否使履约瓶颈从当期削减转向有期限的恢复资源，并改变对给定分阶段接入方案的判断。**贡献需要落实为三类结果：阶段状态与履约能力的明确联系；相同即时MW能力下，由恢复时序引起的方案判断差异；在独立留出路径上，冻结方案的适用边界。

这些是待验证的研究目标。若完整恢复约束始终没有改变方案判断，就据实报告其影响范围；若差异只来自更大的瞬时调用，也不能归因为跨小时恢复。构件组合本身不承担优先权主张，贡献取决于匹配对照和可复核的解释。

## 8 实施顺序与预期交付

实施先完成服务定义和数据映射，形成一个包含阶段变化、响应、恢复与CFE检查的完整小例，并测量计算成本；随后固定少量阶段计划与参数对照，完成主实验；最后冻结策略，用新路径评价并整理图表与论文。

预期交付是一套给定分阶段接入方案的评价方法、阶段性瓶颈与适用边界、可追溯的计算记录，以及完整论文。建设进度作为输入参与评价；后续投资开工时点的联合优化属于进一步研究。网络结论限于声明的DC模型与故障集合，工程应用还需要相应的完整安全校核。
