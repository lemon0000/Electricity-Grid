# Fixed boundaries supplementing182

2026-10-19, DRAFT_NONAUTHORITATIVE. This supersedes conflicting lifecycle wording in182;182 remains preserved. The independent design findings are development findings, not official gate evidence.

1. The registry wrapper encloses the **fixed original Roster phase wrapper, including phase enter, original body and phase exit/cleanup**. Close/receipt/retire occurs after that captured phase wrapper returns and before replay data returns to the caller. The fixed phase route has no external callback; it uses only the original phase runtime and its internally created fixed body lambda. Any phase enter/exit failure poisons this scope, prevents data return and still attempts all cleanup. Do not claim scope closes immediately at the original final journal.rows bytecode. The two `_view` body callsites alone borrow within a replay route; phase entry/exit remains part of that route.
2. Freeze exact caller code, globals and bytecode CALL sites. Standalone view allows only attach's attachment check and the two distinct before/after sites in original `_retain_group_head`; replay's two views only borrow. Top-level replay allows original constructor final replay, inspect and the two original attach replay sites. Locks alone grant no route. The runner's immediate caller must be the final captured registry wrapper (or the original constructor for constructor_owner_replay).
3. Common9 and Common10 each have a distinct **one-time late definition binder** owned by Bootstrap7. At Bootstrap7 definition, capture their two fixed canonical source paths/bytes/compiled module code. Their source-defined module footer invokes the binder only after definitions are complete. Validate exact executing module code/globals, canonical module/file, exact Roster5 import, immutable callable inventory, `_prepare_locked` and its nested check code, exact witness session class/check and existing operation-bridge lease verification. A Common replay is refused until its specific binder is complete. At every allowed Common replay callsite verify the exact active session, original roster/lease, preparing common ticket and creator through the captured session checker. This does not reuse a Common/session nonce as a registry credential, change existing functions after capture, or hold a scope across the Common body. Common9/10 are provisional drafts; their genuine downstream operation bridges remain to be integrated/tested.
4. Pending capsule retains exact scope and original cleanup functions, original Bootstrap owner and creator, plus only a weak Roster reference and unique identity token. Scope records also keep weak Roster identity, no bound Roster method/closure, exception object, traceback or diagnostic object. The active inventory is dropped on all exits; recorded failures are bounded strings. A dead Roster permits only original cleanup/retirement via owner.close. It cannot produce a receipt/body/new validation. Reserve/open failure before a scope exists frees the slot; any created scope must really retire before its slot is freed. Partial/closed Roster.close and closed owner.close retry the same original records. Identity uses weakref plus unique token, never only id.
5. Freeze **1024 successful plus failed detached read observations per Roster** for the bounded one-hour development graph. Check the shared total before reserving a slot, acquiring a helper guard, opening a scope or numerical prepare. The route DAG must be counted before genuine combined diagnostics; if it exceeds this cap, revise the still-unaccepted draft and review before launch. This is not an unbounded or192-hour capacity claim. All owners share the existing16 live-or-pending scope slots.

Required new faults: phase enter/exit while scope active; standalone/private calls with both manually held guards; wrong CALL site with same code; late/unbound/repeated/Common foreign module binding; forged/stale witness ticket/lease; weak Roster death/id reuse with pending scope; observation overflow before any scope/prepare; second-view/final-row failure and third/reentrant view with swallowed inner error. Existing callback, root, cleanup, primary and scientific-equivalence obligations from182 still apply.
