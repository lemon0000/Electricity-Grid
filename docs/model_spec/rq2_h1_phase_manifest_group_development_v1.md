Status: DRAFT_NONAUTHORITATIVE. This is a detached provenance projection, not a
Phase Manifest, producer capability, capacity certificate or execution roster.

`prepare(family, ordinal)` pins the frozen v2 protocol and obligation manifest,
checks the predecessor dependency closure and bookends stable reads. It resolves
every arm actually present in that family at the same other coordinates. Each
sibling retains its complete proof node, ordinal, disposition and missing
dependency. Choosing another sibling gives the same group identity. B6 actual
has only one catalog arm; no cross-family tasks are invented.
The original catalog arm order is retained separately from sorted siblings.
Implementation identity includes repository-relative dependency paths and
absolute paths for dependencies outside the repository, following the existing
symbolic manifest rule. These audit paths do not enter group scientific identity.

Theta and alpha provide the established mechanism, policy and envelope fields.
The old `minimum_recovery_hours` interface denotes interevent rest. E168/F24,
due24, debt retention, unit250 and workload decimal12 preserve the pinned
protocol. Capacity exists only as a candidate coordinate in training UB; it is
never treated as feasible. Audit labels use versioned hashes and are not policy
inputs or execution credentials.

Execution lanes remain unresolved. Training LB needs its same-contract superset
construction. B6 training UB needs separate causal planning tracks, whereas B6
actual uses the shared actual system and requires its training certificate.
Holdout likewise needs frozen training capacity and named policy. Complete
Rref/A selector specs, finite solver/replay configuration and justified archive
bounds remain required. Normal gap1e-8 and residual/lock1e-9 remain unchanged;
this module introduces no numerical acceptance threshold.

No scientific source window, solver, Job, owner, registry or persistent journal
is created. All readiness/resource/formal flags are false. The returned dict is
ordinary mutable planning data and cannot certify a later consumer's freshness.
