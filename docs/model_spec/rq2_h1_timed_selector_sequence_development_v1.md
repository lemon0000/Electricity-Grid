# Complete selector sequence with external timing

DRAFT_NONAUTHORITATIVE. Root-only writer; independent R3 PRE_SEAL review required.
Real execution requires specific new native authority and enclosing owned Job.

The new owner explicitly calls the timed stage producer and a fresh joint reader
for every configured stage. It writes the legacy scientific commit first, verifies
its bytes, then writes and verifies a separate timing commit. These two journals
are not atomic. Any exception permanently poisons the live owner. Partial writes,
unequal prefixes, missing counterparts and unknown suffixes remain preserved and
cannot be resumed or reused as successful timed execution.

Scientific headers, commits and terminal retain the old wire contract so the
closed legacy sequence inspector can independently reconstruct numerical science.
The new owner never instantiates the old owner or creates its completion type.
Old implementation identities identify serialization/scientific replay, not an
authenticated execution of the old producer. All execution/consumption flags stay
false. The new completion is bound to exact live type/object/guard/nonce and bytes.

The external timing root contains binding.json, stages, commits and terminal.json.
Its header binds complete scientific configuration, both roots, scientific root
inode/header pin, common nonce, new implementation, timed stage implementation,
PID/thread/QPC and independent logical byte cap. The conservative cap is checked
before directory creation: two sequence metadata caps plus one commit cap and
six stage timing files per stage. It excludes filesystem allocation and RAM.
Both actual header envelopes are checked before any mkdir. The timing header
precheck uses maximum-width directory identity integers; actual identifiers must
be exact nonnegative integers at most 2**256-1. This is an explicit serialization
bound, not an assertion about operating-system capacity.

Each timing commit links its predecessor, exact scientific commit hash, stage
index/label/request, scientific and timing terminal pins, owner and absolute
windows. Saved replay bookends both archives and repeats the closed science and
joint timing inspectors. It checks complete prescribed stage order, same owner,
ordered nonoverlapping stage windows, native containment and bounded integer sum.
The live owner retains complete file and directory stamps across stage releases,
including the original scientific header, so same-byte file replacement cannot
silently establish a new live prefix.
Initial and final views are bound through canonical immutable fingerprints of
relative paths, directory tuples, file caps, content hashes and complete stamps,
including all stage children. The initial digest belongs to fixed owner state;
the final digest belongs to the private completion and its receipt fingerprint.
Rewriting both a saved snapshot and its files cannot move the original trust pin.
After the science terminal passes the old inspector, the timing terminal binds
both final heads, science terminal, timing binding, full vector and aggregate.

The constructor-to-preterminal clock window includes possible idle time before
run and excludes terminal publication/final inspection. It is an ownership
diagnostic only, not a Job interval or verified non-solver budget. A detached
inspection proves consistency of supplied records, not historical execution or
clock honesty. All whole-Job, resource, continuation, formal and consumption
gates remain false. Worker transport, parent quiescence, phase accounting and
paired phase commit still require integration.
