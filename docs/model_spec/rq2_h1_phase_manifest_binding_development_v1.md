# H1 phase manifest binding development v1

Status: DRAFT_NONAUTHORITATIVE. Detached declaration only. No executable manifest,
owner capability, source authentication, solver producer, resource admission or run authority.

The public `prepare(training_ub, ordinal, selector_configuration, archive)` freshly
loads and reprojects the pinned family group before and after construction. It binds
the full four-arm obligation group, full selector/Job/non-solver declarations,
capacity labels, accounting period, lane declarations and implementation identity
in canonical audit bytes. Its digest is an audit identity, not a scientific decision
key. The returned dataclass is manually constructible and is not a credential.

Unresolved network-only, CFE-only and joint-correct obligations map to distinct
shared Actual LaneConfigs under one accounting period. Unresolved joint-B6 remains
`pending_separate_B6_planning`; training UB B6 must retain separate grid/CFE planning
tracks. Proof-terminal siblings remain in the audit. No sibling is silently removed
from the original catalog. Other families fail closed. An empty direct roster has
no Manifest. Group completion remains false even if all siblings have proof dispositions.

Frozen capacity and mechanism numbers are parsed exactly; conversion to legacy
built-in scalar fields is allowed only when decimal round-trip is exact. The v2
q+r<=D policy, CFE preallocation, 168-hour enrollment plus 24-hour follow-up,
due offset and retained debt/birth semantics remain unchanged. Candidate capacity
is a declaration, never a feasible capacity certificate.

The adapter rejects scientific-field inventory expansion or omission, changed
group claim/gate semantics and disposition/dependency mismatches. The training-UB
group requirement `complete_training_causal_policy_and_grid_witness` corresponds
to unresolved sibling dependency `named_causal_policy_full_training_witness_missing`;
terminal proof siblings require no missing dependency. Tests include pinned ordinal
11832353: D=1/100, one unresolved network lane and three proof-terminal siblings.

Archive arithmetic reserves 2 origin events, 191*3 subsequent events and one
episode terminal: a full-192-hour primary upper bound of 576. Each reserved alternate
witness adds two events. `reserved_alternate_witnesses` is a planned allowance;
the current owner does not enforce a separate witness count cap. Therefore the
count formula is conditional, and full-path archive sufficiency remains unproved.
The event count must fit the holder's 999999-ticket ceiling. Declared archive bytes
must cover max_events*max_event_bytes. The event declaration must also cover the
exact base64/JSON envelope of maximum-length saved selector records for one shared
reference and all direct Actual lanes. This envelope excludes source audit, intent
metadata and event framing; full event size, physical storage, host and runtime
bounds still require proof. No large synthetic records are allocated by preparation.

Acceptance: exact frozen projection and all siblings; faithful rational mapping;
B6 separation; typed declaration and archive rejection cases; independent encoded
record-size oracle; source/projection and implementation drift rejection; zero
solver/Job tests; related group/config regressions; independent read-only R3
pre-seal audit; predecessor pin and frozen artifact retention. All formal gates stay false.
