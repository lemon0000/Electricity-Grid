# N-layer factorized symbolic manifest

2026-10-09. DRAFT_NONAUTHORITATIVE. Root is the sole writer.

The input is the exact pinned proof-aware obligation manifest. No source loader,
solver, controller, Job or launch request is used. The compiler verifies its
970-pin predecessor evidence and repeats stable input reads before returning.
The result is an immutable snapshot; inspection reconstructs it from current
pinned bytes. StaticProfile is only a caller declaration, not an admitted profile.

Each unresolved obligation has a separate potential N episode with 192 slots.
Slot ordinals are `original_obligation_ordinal * 192 + relative_hour`; the domain
is sparse because proof-discharged ordinals return proof references, not slots.
All original obligations remain represented, including incomplete source tails.
The partition is recomputed from cell/arm proofs and catalog axis cardinalities.

N slot predecessors strictly decrease the hour; hour0 has a declared genesis.
Enrollment is 0..167 and followup is168..191. Activation is a runtime owner
decision; holdout also requires the frozen-training barrier. Declaring these
rules does not implement them. Source, carry, request, process and outcome
identities remain null. Failures cannot be interpreted as successful service.

The count of 588,470,227,968 potential N hours is conditional on one globally
registered episode per unresolved obligation, one attempt per slot and no retry.
No global registry enforces that condition yet. It is neither an eligible count
nor a complete-study bound. Stage counts are explicitly conditional: the
232-stage multiplier applies only after exact fixed RTS N stage-order/profile
validation. StaticProfile binds a declared stage-order SHA but this unit does
not validate that declaration. It is not a bound for arbitrary profiles, other
models, Rref/A or LB/UB policy search.

Candidate classes omit theta/alpha/arm/D, but retain split, complete source pair,
hour, declared network/DC/config/specification/limits/budget/implementation/stage order,
origin/need rules and predecessor class. Their 5,564,160 pair-hour cardinality is
only a candidate quotient. No reuse edge, numerical equality, accepted result,
unique producer or resource discount follows from it. Runtime carry equality,
fresh accepted replay and global publication/conflict checks remain required.

The following remain false: complete_executable_task_inventory,
causal_request_keys_materialized, solver_reuse_verified, resource_admission,
formal_execution_ready, formal_result and native_execution_authorized.
Rref/business/A/LB/UB-policy multiplicities and complete resource envelopes are
unresolved. This unit cannot authorize another use of the consumed v3 lease.
