# B2最小DC网络连接规格

2026-10-22，`DRAFT_NONAUTHORITATIVE`。上游为[A规格](staged_deliverability_minimum_spec_v1.md)与[B计划](../plan/staged_deliverability_small_case_plan_v1.md)。本包复用仓库两母线并联线数据结构和PYPOWER `makeBdc/dcpf`，连接给定工程、实际业务取电及完整F/X网络检查；是合成网络开发，不是场址、AC、一般SCED或安全认证。

## 1 固定输入与网络范围

独立输入为[网络DRAFT配置](../../configs/staged_deliverability_network_v1.DRAFT.yaml)，绑定B1业务fixture的SHA，不修改B1输入、实现或已保存工件。

- 两母线、两条1→2并联线，单在运源位于母线1、POI在母线2；base=100 MVA，x=0.1 pu，tap=1、shift=0。背景负荷0.1 MW位于POI，源范围0…2 MW，无经济调度自由度。
- 工程在s=0开始、L=2小时后投运，延期路径额外2小时。每条既有线的热限由0.725增至1 MW，投运前不增容；阻抗和拓扑不变。小时工期仅为机制时间压缩。
- F/X分别为工程前0.6/0.2 MW、工程后0.8/0.5 MW。额度随实际投运释放，是预先给定的计划规则。参考业务需求仍外生；不能为接入权不足缩小w。
- 声明故障集合为分别退出任一并联线。实际路径仅t=1发生小时开始前已知的计划性线路0退出，持续一小时，采用小时级预防性调用；没有突发故障的同小时纠正响应、亚小时响应或短时额定值结论。安全枚举不当作每小时真实故障，不累计其事件次数。
- 另核实际X包络：最多0.5 MW、爬坡0.5 MW/h、持续1 h、2事件、累计0.5 MWh、最小休息0 h；源每小时变化不超过2 MW。计量点所有CFE、自主移峰及补做已纳入业务P，背景负荷不属于该CFE计量点。

## 2 DC计算、上界与独立检查

固定平衡规则为G=P+L_bg，正向潮流从源至POI。任意母线ID先显式映射为0起连续内部编号。PYPOWER输入用pu注入，输出角度为rad、潮流乘base还原MW。重新检查所有节点（包括参考节点）的平衡、支路方程、故障线零潮流、发电界、热限及声明角度界；容差固定1e-9，不以求解器返回代替残差检查。

本受限无移相并联网络可精确求POI区间：μ_i=(1/(x_i tap_i))/Σ1/(x tap)，f_i=μ_i(P+L_bg)。每个在运支路、源上界及角度界分别形成上界并取最小；无在运连接时拒绝，不能补一个无限slack。预期热限主导的正常/单线退出上界分别为工程前1.35/0.625 MW、工程后1.9/0.9 MW。PYPOWER数值潮流与独立Fraction分流及节点余额交叉核对。

上界仅适用于所声明的单源、正电抗、零移相、非负POI负荷和背景负荷。多源、一般背景分布、负荷反送、电压/无功、发电机退出及经济再调度属于后续范围；输入不支持时明确拒绝，不能泛化本公式。

## 3 四类账与准入语义

1. **参考请求**：从当前实际拓扑求g=max(P^0−H_physical,0)，保留完整值，不截到X或D。正常状态不借X调用掩盖计划超额需求；本固定策略要求P^0≤F+X，超出时记录reference_connection_shortfall并停止该参考准入策略。这不是所有可能运行策略均不可行的证明。
2. **实际运行**：只有声明的预防性线路退出可调用网侧X；g≤max(P^0−F,0)≤X，并受X包络限制。传给B1策略的当期上界为min(H_physical,F+X)，用于当前延期与恢复；前置准入确保不会把接入额度缺口伪造为网侧请求。实际P重新调用PYPOWER验证，源变化和X预算均通过后才提交业务账本。
3. **完整网络合同**：正常状态核完整C=F+X；每个声明退出状态核F以及C−c_hat，其中c_hat=max(C−H_fault,0)≤X。独立保存响应功率/一次事件能量必要条件。枚举不使用实际低负荷替代完整合同，也不累计所有互斥退出的事件预算。
4. **完整合同下业务必要条件**：在同一设备、待机和辅助功耗下，声明反事实w_hat=(C−P_idle*γ−P_aux)/a，h_hat=max(C−Y/α,0)。对正常和各故障分别检查q_hat=(c_hat+h_hat)/a≤D、q_hat≤f*w_hat及0≤w_hat−q_hat≤K。另独立核整段登记X的瞬时背书必要条件X≤aD、X≤a*f*w_hat且w_hat≥0；逐场景条件不受该项门控，聚合业务条件取两者合取。只是一小时必要条件，不创建实际任务、不改实际债务，亦不证明恢复/期限支持。

完整网络层通过与完整业务必要条件失败可以同时出现；这些结果必须并列保存。即使所有一小时必要条件满足，仍标记joint_temporal_support_unresolved，不授予容量释放、certification或正式可交付结论。实际低负荷轨迹是给定计划下的条件诊断，不能推翻已观察的完整合同缺口。

输入中的post X=0.5 MW已大于aD=0.25 MW；选定故障的最小完整合同调用为1.3−0.9=0.4 MW，即使无CFE请求也超过业务D。因此本计划在post阶段的业务支撑必要条件应失败，aggregate_contract_release=false；不能只写成CFE叠加后“可能失败”。这项保留的解析反例用于防止把网络见证当作完整接入方案通过，不通过调整D或X制造有利结论。

实际业务沿用B1独立加总、q*r=0和共享D；网侧削减不能削减受保护F，CFE自主少用F不改变其接入权。X调用/爬坡仅按a*c_grid记账，不能把CFE自主削减计入X调用上限；源按前一实际出力至当前实际出力检查小时爬坡。不能仅因最终潮流合格就跳过这些条件。

## 4 事务、前史与重开

每小时从原状态读取完整任务/逾期、事件/累计预算及上小时实际源出力；只观察当前业务、设备、工程和线路状态。先求参考请求与合同诊断，再产生业务提案；真实DC、合同、响应或源爬坡检查失败/未决时保存提案和原请求，业务债务与物理出力保持上小时值，停止依赖后缀。缺失输入不当作零请求。

独立增加X事件、持续时间、休息、累计MWh和前一X调用状态；工程投运、登记边界及重开均不重置。保存t=1末状态；新进程按调用者绑定的前缀重新执行后比较全部业务、网络与X状态，再执行后缀。完整合同的互斥故障枚举不写入实际X状态。

## 5 开发验收与性能准入

普通测试先验证双线/单线精确潮流、非连续母线ID、节点/支路残差、热限/源界、孤岛拒绝、投运时点、正常完整C与故障F/X分离、活跃X/响应/预算、工作量与P、失败不提交、期限及重开。独立审计不得调用被测潮流/上界函数。

有界整路径诊断另按agent.md第9节登记后执行：三条B1匹配路径，仅完整时序固定策略；每条连续参考及fresh-process前缀重放/后缀比较；保存正常/故障/full-C/actual工件、分阶段wall、PYPOWER潮流次数、内存/存储、版本与SHA。无优化solver、无新native校准。实际调用量、源包依赖、预算与未知故障成本须在启动前补入执行合同。
