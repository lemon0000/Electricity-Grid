# Hour-zero selector input snapshot reconstruction

DRAFT_NONAUTHORITATIVE. Root-only development; independent R3 pre-seal review
required. No producer, Job, phase publication or continuation entrypoint.

Capture accepts the exact live CommonOwnerGenesis under its original guards,
requires its complete three-event binder and empty holder/owner receipts, and
bookends common/source/configuration correspondence. The fixed canonical snapshot
contains typed declaration data and audit pins, not serialized frame, disclosure,
SelectionCandidate, business carry or executable class tags. A 4MiB byte cap and
exact field inventories apply before source reconstruction. Fixed explicit
decoders require canonical round trips, reduced rational strings and agreement
between Manifest and SelectorRunConfiguration.
The projection also retains the complete canonical declaration SHA as a separate
audit identity, covering labels, archive caps and receipt provenance which are
intentionally absent from scientific decision identities. Common roots must be
exact canonical absolute strings.

Rebuild is solver-free. Two fresh phase._fresh / phase._initial / phase._request
rounds must match the retained scientific and audit projection. It reconstructs
the current frame, disclosure and each lane's own zero-hour before-state. The
sequence's full configuration checks validate network, sorted UID inventory,
selector/specification/limits and logical archive reservation.

Reference snapshots have no Actual lane or dependency. Actual snapshots require
an already complete Rref archive and externally supplied terminal/request pins.
Both passes inspect that archive against the same reconstructed source/state and
run configuration. The exact Rref grid request (B minus P_ref) feeds the existing
business.current and business.prepare_development rules; their exact rational
actual power constructs RelativeDcPower. The API has no supplied-power field.
Unknown lane, incomplete Rref or unresolved business candidate is rejected.

The detached result is a constructible diagnostic container. Its source science
is freshly rebuilt, but its recorded common-owner receipt is historical capture
provenance: rebuild does not reopen a live owner, certify its current on-disk state,
authenticate a past native execution, or prove whole-Job quiescence. A later owned
controller must validate live common correspondence, retain release/Job receipts,
wait for full Job exit and freshly inspect output before any state consumption.
Handmade snapshots or matching hashes cannot supply that capability. All such
authority flags remain false, including on successful capture/rebuild.

Only hour 0 and empty genesis are supported here. Full192/hours1+ require a
separate independently reviewed read-only phase-prefix reconstruction interface.
Existing N snapshots and writable phase-owner constructors do not provide it.
Tests use explicit synthetic source/roster seams, real genesis journals and
fabricated direct-adapter Rref archives; no actual RTS integration or native
optimality is inferred. Frozen predecessor bytes and failure evidence are kept.
