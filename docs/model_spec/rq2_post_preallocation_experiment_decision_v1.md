## 对论文主指标的直接影响

原规格 `rq2_joint_deliverability_estimands_v1.md` 和原preregistration要求完整training支持审计。
完整支持被反例证伪或注册上限被证明不可行时estimand undefined；审计或证书不完整仍为unresolved。
新有限候选以 `inf(empty)=+infinity` 表示无可行容量集合，
这是数学说明，不是将旧正式状态改成一个可参与减法的数值。

在当前全支持候选下，CFE-only、joint-correct及B6 CFE规划账均被反例排除有限D；
network-only的结论仍须独立取得。于是：

- `I_joint=D_J-max(D_N,D_C)`、`I_sep=D_B-max(D_N,D_C)`、`A_B6=D_J-D_B`
  都不能从这些结果计算为有限数字，也不能把 `infinity-infinity` 置零。
