# B1有界开发诊断：执行合同与成本测量

2026-10-22，`DRAFT_NONAUTHORITATIVE`。目标是验证[小案例计划](staged_deliverability_small_case_plan_v1.md)的B1连接，并保存可独立检查的9条机制轨迹；实际网络B2及主实验预算仍未闭合。本包不调用solver/native、不下载数据、不创建production manifest、lease或正式运行权限。

## 执行路径与固定规模

父进程读取本包代码、fixture和旧债务ledger的SHA及运行环境→加载3组输入→每组执行三种方法→独立逐行审计→保存t=1末checkpoint→启动一个全新子进程→子进程重放已绑定前缀、继续后缀并独立审计→父进程比较完整终态→两次离线flow及子集割核对→写报告→输入SHA复核→关闭。

- 连续参考9×10=90个策略步骤；回读验证明确重放9×4=36个前缀步骤；重开后缀9×6=54步，总计180步。禁止把回读重放埋入I/O计数。
- 父进程审计9×10=90步，子进程终态审计再9×10=90步，合计180个独立审计步。保存9份checkpoint、9份终态，启动9个子进程；父进程加载fixture 3次，子进程各1次，合计12次。
- 离线oracle只对按期计划的早/晚完整路径各1次，共2次；本例各1笔延期债务，并各做1次非空子集割核对。它只回答固定债务的离线恢复问题。
- 重复写拒绝、截短、参数/期限/设备/状态篡改等失败路径由普通pytest覆盖；本次成本测量只覆盖成功保存/重开及包含期限违约的机制轨迹，不声称测到I/O中途失败或昂贵故障收尾。后者在C中补齐。

## 优化与等价

代码与原始fixture仅在开始/结束各hash一次；每条轨迹线性执行一次、重开仅重复一个明确前缀及后缀，不使用旧H1构造器、Job或整条历史链。旧ledger只记账，功率和资源检查在新层实施；独立审计不导入被测功率、动作或ledger更新函数。两种近似方法的债务是反事实计划账本，全约束回放单列首次拒绝和拒绝前债务，不能记为实际任务已完成。

首例保持同小时调用/恢复互斥、共享D、任务/功率守恒、未投运资源禁用和期限快照。读回以调用者绑定的前缀重新执行并比较完整payload；不采用未证明等价的缓存。9个子进程依次启动，避免改变算法及峰值资源；固定小规模下重复前缀校验优先保证可追溯性，其36步成本单列。

## 上限、故障与结论边界

父进程诊断墙钟上限60 s；每个子进程15 s上限。父进程在每小时、每次审计/持久化、轮询子进程和收尾检查时间、采样RSS及输出大小；同进程同步文件操作不能被检查点硬中断，不能把检查点保护称作OS硬配额。预算偏离后终止本包创建的子进程，保留attempt和failure终态，不修改历史attempt或顺延预算。

父/子进程树采样RSS合计上限512 MiB，输出16 MiB，单checkpoint/终态1 MiB，fixture输入1 MiB。RSS是采样观测，可能遗漏瞬时峰值。子进程轮询不超过0.05 s；阶段心跳写入events.jsonl。故障时记录已完成阶段、计数和错误，原输出保留。

本包先核对窄测试、完整调用量、输出范围及版本，再按上述固定规模测量；这是agent.md第9节允许在开发范围内开展的有界整路径诊断，不递归要求先有本包的实测成本。测量报告绑定实际代码/config/ledger的SHA和环境，并明确覆盖/未知阶段。本报告只能支持B1成本，不能外推B2、168/192小时或正式实验。
