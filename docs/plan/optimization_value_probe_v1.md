# B 与 B2 可行性验证:为什么优化不改变可交付判定

2026-11-07,`DRAFT_NONAUTHORITATIVE`。本文件记录一个**否定结果**:在当前模型族下,把运行策略从贪心换成最优,不改变任何可交付判定。它推翻了本会话早先"换最优能强化论文"的判断,留档以免重走。

## 1. 背景

用户选择路线 B(加入优化问题)以提升 TSG 录用概率。核心设想:现有 `full_temporal` 用贪心规则(先电网、后清洁、空闲才恢复),把它换成最优调度,则论文主张从"简化方法错了"升级为"即使最优运行该计划也不可交付"。

本验证检验这个设想是否成立。

## 2. B(标量模型最优)——差距为零,物理决定

**单元 `fast/on_time/early` 的逐小时恢复余量:**

```
h1  产生 1/5 债务,期限 h3
h2  无请求,但物理恢复余量 = 0
h3  期限到,物理恢复余量 = 0
h5  第一个恢复余量 > 0 的小时(1/5),但已过期限
```

期限窗口 [h1, h3] 内每一小时的物理恢复余量恒为 0。任何策略——贪心或最优——都无法在零余量的小时偿还债务。**1/5 的逾期是物理不可避免的,不是贪心规则造成的。**

三条独立证据:

1. 本单元期限窗内余量恒为 0。
2. 判据 A 的 39/39 验证(上一会话):逾期完全由"恢复余量在期限窗内是否足够"决定,这是外生物理量。
3. D 每个单元只有单个 cohort,无多任务调度空间。

## 3. B2(跨小时任务转移)——差距仍为零,结构性

B2 设想一个更强的模型:任务有到达、期限、能量,调度器选择在窗口内哪些小时执行,受逐小时 N-1 容量约束。用真实 RTS-24 母线 15 容量剖面(6-728 MW,波动 2 倍)做探针。

**探针结果(`experiments/b2_shifting_probe_v1.py`):**

| 基准负载 | 贪心逾期 | 最优逾期 | 差距 |
|---|---:|---:|---:|
| 200 MW | 91.3 | 91.3 | 0 |
| 300 MW | 182.9 | 182.9 | 0 |
| 400 MW | 576.6 | 576.6 | 0 |
| 500 MW | 707.8 | 707.8 | 0 |

此外用三种**专门设计来暴露差距**的任务结构检验(competing、valley-straddle、tight-vs-slack、forced-harmful-EDF),差距全部为零。

## 4. 为什么差距必然为零(理论原因)

B2 的调度问题是:**单资源(逐小时容量)、任务可分割、线性目标(最小化逾期能量)。**

对这类问题,**最早期限优先(EDF)+ 贪心填充本身可证明最优**,这是经典调度理论结果。逾期只在以下情形发生:

- 任务窗口完全落在容量不足的时段(如 B2 探针里 task [5,9] 落在容量谷),或
- 窗口内总可用容量 < 任务总能量。

两种情形都是**物理不可行**,与调度策略无关。最优调度不能凭空创造容量。

因此:**只要任务可分割、资源是标量逐小时容量,最优 = 贪心。** 这不是案例设计的偶然,是问题结构决定的。

## 5. 什么情况下 B2 才会有价值

差距非零需要打破"EDF 最优"的前提,即引入以下之一:

1. **不可分割任务**(任务必须整块执行)→ 变成 bin-packing,NP-hard,EDF 不再最优。
2. **启动成本/最小运行时长**(任务一旦启动有固定开销)→ 整数约束。
3. **容量随调度决策变化**(如任务的网络注入点不同,影响潮流)→ 耦合。

这些都是**实质性的新模型**,不是现有标量机制链的扩展,需数周级开发 + 新 R3 审查 + 6.1-6.4 重算。且即便引入,仍可能因真实容量谷太深而回到"物理决定"。

## 6. 对论文路线的结论

**B/B2 在当前模型族下不提供优化贡献。** 不应为迎合 TSG 而强行引入——那会是一个差距恒为零的"优化",审稿人会识破。

真正成立的是一个**更强、更诚实的结论**:

> 分阶段接入计划的可交付性,由恢复余量/网络容量在期限窗内的时间可用性决定,**与运行策略的优劣无关**。贪心与最优给出相同判定。因此简化评价的失效不能用"换个更好的策略"来补救,只能通过改变计划、容量或期限来解决。

这把论文从"简化会错"推进到"**失效是计划-网络的结构性质,不是运行问题**",并配合:

- 两条可判定判据(A/B,39/39)
- 求解器算出的真实 N-1 容量(阶段 0/1)
- 贪心=最优的证明(本验证)

这是方法论贡献,适合 TPWRS 方法类或 Applied Energy;投 TSG 仍有外部有效性风险,但不靠虚构优化。
