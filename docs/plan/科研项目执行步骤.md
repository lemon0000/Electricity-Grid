# 智算中心分阶段接入与小时级绿电协同规划：科研项目执行步骤

## 一、项目最终要回答什么

本项目只围绕三个研究问题展开：

1. 当数据中心达产和电网扩建进度逐步揭示时，多阶段自适应接入相对静态接入和两阶段规划有多大价值？
2. 在网络安全调用保持为硬约束时，小时级CFE目标提高会怎样改变联合业务柔性可交付前沿？联合时序交互与B6分离记账会形成何种容量偏差和场景外履约风险？条件容量X只在显式建模或建立可验证映射后讨论。
3. 年度绿电匹配与小时级清洁电力匹配会不会产生不同的接入容量、扩建时序和业务调度决策？

毕业论文/首篇投稿的主创新是网络安全与小时级CFE共同约束下的业务柔性可交付前沿与不足归因（RQ2），后续扩展是多阶段自适应F/X容量释放（RQ1）。恢复债务、CVaR、N-1、代表周和公开边缘transport属于支撑模型，不分别包装为创新。

> 论文主线聚焦说明（2026-09-03，用户决策）：本文件描述的是**完整三问项目蓝图**，是长期科学契约。毕业论文/首篇投稿在此蓝图内聚焦RQ2的联合服务可交付前沿：四臂最低柔性曲线、`I_joint = I_sep + A_B6`归因和固定策略共享执行。B6为分离时序记账诊断，公开边缘transport为holdout稳健性层。`agent.md` §4是创新定位权威；确认性协议见`docs/plan/RQ2_联合服务可交付前沿确认性方案_v2.md`。

## 五、第四步：复现基础电网并完成确定性MVP

不要一开始加入随机规划和绿电。先保证最基本的网络模型可信。

### 依次实现

1. 导入RTS-24并复现基础DC潮流或DC-OPF；
2. 检查节点功率平衡和线路潮流；
3. 建立关键N-1故障潮流；
4. 加入候选线路或主变扩建；
5. 加入一个固定节点、固定规模的数据中心；
6. 设置确定性的季度达产路径；
7. 让模型选择是否扩建以及何时扩建。

### 必须通过的测试

- 数据中心负荷为零时，结果回到基础系统；
- 网络容量无限时，不发生网络削减；
- 扩建成本极低时，模型倾向提前扩建；
- 扩建成本极高时，模型不会无条件建设；
- 候选工程只有在工期结束后才能提供容量；
- 所有关键N-1状态均无热越限；
- DC最优方案能够通过AC潮流事后检查，或能解释偏差来源。

### 产出

- 基础潮流表；
- N-1越限表；
- 候选扩建结果；
- 一个可重复运行的确定性MVP。

## 六、第五步：加入分阶段F/X接入机制

### 实现内容

- 定义保供容量F；
- 定义条件容量X；
- 删除独立的U容量变量；
- 扩建完成后，通过接入点容量上限允许后续F/X增加；
- 定义条件容量调用的触发、持续时间、事件次数和能量预算；
- 定义首个可运营容量块B_min；
- 计算T20、T50和T100。

### 首先完成三种基线

1. 等待全部扩建完成后一次性接入；
2. 按确定性达产曲线分阶段接入；
3. 静态F/X接入，不允许根据后续信息调整。

### 必须检查

- F在规定N-1集合下不因网络拥塞削减；
- X只能在约定条件内调用；
- 实际服务功率、合同削减和非合同服务缺口严格区分；
- T20不能由1 MW或其他无运营意义的容量触发；
- unused MW-year只作为物理指标，不随意货币化。

## 七、第六步：加入场景树和多阶段适应性

### 先从小场景树开始

M5a机制门冻结为`rts24_b3_b5_synthetic_tree_v1`，机器输入位于`configs/rts24_stochastic_baselines.yaml`。小树采用六条递进需求路径乘两个工程状态的完整全因子设计，避免需求与工程效应混杂，也避免q2信号提前泄露完整需求路径：

- 六条需求路径分别为`50/50/100/200`、`50/50/100/250`、`50/100/200/200`、`50/100/200/250`、`50/200/200/200`和`50/200/200/250 MW`，只复用M4需求里程碑且共享q1初始状态；
- 工程`E0/E1`分别为现有2季度基础工期加0/1季度；
- 每条需求路径权重`1/6`、工程状态权重`1/2`，十二叶各`1/12`，只表示平衡合成机制设计，不是经验达产率或延期率；
- q1根决策不观察长期因素，q2前只揭示当前需求类，q3前揭示外生工程交付环境，q4前才揭示终端需求200/250 MW；
- B3全期12叶同一规划决策组，B4按`1 -> 3 -> 6 -> 12`组演化，B5从q1起为12个单叶组且机器标记`implementable=false`。

M5a还必须用`rts24_common_fair_inputs_v2`重算M4公共输入SHA-256；冻结值为`76cda29db68705cc3f2ef5025f32d30ef07ceea62a552a97c45b01bf83287794`。季度小时、负荷倍率、POI、工程、服务包络、安全状态、再调度、目标或solver任一漂移时，不得继续随机模型。

不要一开始为每个季度建立大量分叉。先用这棵四季度小树验证信息结构，再逐步增加复杂度。工程信号当前是外生审批/供应链/交付环境；真实项目自身进度会产生决策依赖的信息揭示，不能用本小树冒充。

### 依次建立

1. 确定性分阶段模型；
2. 两阶段随机模型；
3. 多阶段随机模型；
4. 完美信息模型，作为理论下界。

### 核心检查

- 相同历史节点的F/X和扩建决策完全一致；
- 单一确定场景下，两阶段与多阶段结果一致；
- 多阶段模型只能利用当前已经揭示的信息；
- VMA在相同外样本和相同安全标准下计算；
- 如果VMA接近零，应作为有效结果，而不是修改参数直到得到正结果。

## 八、第七步：加入完整业务灵活性包络

### 负荷拆分

- 刚性业务：关键推理、网络、存储和必要基础设施；
- 柔性业务：可暂停、延迟或降频的训练及非关键任务；
- 非恢复损失：被放弃而不是延期完成的业务，单独计量。

### 加入约束

- 可削减MW；
- 最大连续削减时间；
- 最大事件次数；
- 事件间最小恢复时间；
- 累计削减能量；
- 恢复债务；
- 恢复功率上限；
- 期末债务边界。

### 时间样本要求

必须使用连续代表周或连续压力窗口。无链接代表日不能用于证明最大持续时间、事件次数和日际恢复债务可行。

### 对照实验

- MW-only灵活性模型；
- 完整持续时间模型；
- 完整持续时间+事件次数+恢复债务模型。

比较它们对X、业务违约和恢复峰值的影响。

## 九、第八步：加入年度和小时级绿电

### 先做年度匹配

约束年度可归属清洁电量达到数据中心年度用电量的一定比例，验证基本能量平衡。

### 再做小时级匹配

要求每个小时的可归属清洁电量达到该小时数据中心用电量的目标比例，同时满足网络潮流和新能源可用出力。

### 绿电建模边界

- `y_CFE`表示同小时可归属清洁电量；
- 不声称追踪电子的物理来源；
- 网络模型证明清洁注入和数据中心取电能够同时实现；
- MVP不加入储能属性追踪和绿证交易；
- 绿电缺口与电网服务缺口分开统计。

### 最关键的统一预算

网络条件削减与绿电移峰必须共享同一个柔性负荷上限：

```text
c_grid + c_green <= D_flex
```

同一工作负载不能同时被承诺给两类服务。

### 必做对照

- 无绿电目标；
- 年度绿电匹配；
- 小时级CFE匹配；
- 允许灵活性重复承诺；
- 禁止灵活性重复承诺。

## 十、第九步：完成三条核心证据链

## 十一、第十步：进行场景外验证和规模扩展

### 场景外验证

使用与训练场景独立的需求达产、工程延期和新能源路径执行已经得到的策略。

场景外评估时不能重新使用完整未来信息优化，否则会把策略执行误写成完美预见。

报告：

- 指标均值和分位数；
- CVaR；
- 置信区间；
- 履约失败概率；
- 极端联合情景；
- 参数错设和分布外压力测试。

### 规模扩展

确定性MVP和核心机制稳定后，再迁移到RTS-GMLC：

- 扫描多个候选POI；
- 区分局部主变、输电走廊和系统性瓶颈；
- 使用多个候选扩建项目；
- 进行关键N-1筛选；
- 对代表性最优方案进行AC复核。

不要把“从24节点换到更大测试系统”直接当成泛化验证。更重要的是多POI、多瓶颈类型和场景外稳定性。

当前已完成该步骤中的六候选多POI、共同selected-N-1比较、混合可行/不可行处理、两个代表方案的amendment-004 direct AC sensitivity，以及零数据中心正常态对照和三层AC恢复诊断。direct AC安全门为`0/2304`，零注入对照为`0/24` secure，且官方电压边界内仍有h15/h21未取得AC可行性见证，因此不能进入论文结果固定。多个候选扩建项目、独立经验场景外统计和工程级AC恢复/认证仍未完成，本步骤只达到范围性benchmark诊断门。

## 十三、第十二步：按证据写论文

推荐写作顺序：

1. 先写Problem Setting和数学模型；

- F/X在不同制度下的可能映射；

- 未纳入储能、市场和电价的原因；

## 十四、项目全过程的停止规则

出现以下情况时不要继续叠加新模块：

- 基础潮流和N-1尚未验证，就开始多阶段模型；
- 非预见性尚未通过测试，就加入小时级绿电；
- 恢复债务依赖无链接代表日；
- 只有人为调高拥塞或延期时方法才有优势；
- 结果完全由任意货币权重决定；
- 绿电只增加成本，从不改变接入、扩建或灵活性分配；
- 多阶段、重复承诺和小时CFE三条证据链均无辨识度。

遇到这些问题，应先缩小模型、修正规格或降低论文主张，而不是增加强化学习、储能市场、复杂博弈或更多优化算法。
