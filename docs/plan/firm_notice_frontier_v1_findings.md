# 方案A合同边界诊断：Firm容量、通知与阶段资源

2026-11-09。DRAFT_NONAUTHORITATIVE，预先固定的合成离散合同菜单；不代表真实站点MW、经济收益或已成立创新。

## 结论

在本模型和菜单内，通知可以在部分业务条件下替代一个Firm档位；替代有阈值与饱和，阶段恢复资源较晚时也可能消失。精确DP与补强JIT强基线全部一致，因此正结果支持合同边界的机制与决策后果，不支持新调度算法优势。

## 可复核合同例子

所有量归一化，保护负荷始终占1，总Firm可选1或2。保存需10分钟，初始未保存进度0，剩余工作13单位，原期限60分钟，阶段正常供电在30分钟从2升到3。

|通知提前量|菜单内最小总Firm|
|---|---:|
|0分钟|2|
|5分钟|2|
|10分钟|1|
|20分钟|1|

从5到10分钟通知，低Firm合同由不可履约变成可履约；从10到20分钟不再下降。这是该任务与模型的阈值，不是普适10/15分钟界限。菜单只有两个Firm档位，不能声称连续最小Firm等于1或真实节省50%。较高Firm意味着较低的调用期削减义务，不能表述为相同MW电网响应下的免费收益。

同一R=13、10分钟通知，将阶段供电升级从第10/30分钟改为第50分钟，菜单内最小Firm从1变成2。通知与阶段资源的组合改变合同可行性，不仅改变运行曲线。

R=17、升级30分钟时，所有预设通知均需总Firm2。低Firm合同即使没有保存损失，非调用期总工作能力也只有16单位，已低于17，因此通知不能完全替代保障资源。

## 物理与信息口径

正常供电按已知阶段增加，合同Firm只决定事件t4/t5内的保障能力。低Firm要求任务域关闭，回滚未保存进度；高Firm允许受限继续执行或完成保存。强制关闭是明确情景假设，不是任意功率降到某值必然丢数据的定律。没有UPS/保活/迁移等替代控制。

通知前所有方案同策略，事件时点收到通知才知；原期限不变。升级时点全程已知，无随机施工延期或多任务。初始准备状态为给定；未优化长时准备策略。研究对象是单一已知事件下的条件合同边界，不是跨事件无限期安全保证。
