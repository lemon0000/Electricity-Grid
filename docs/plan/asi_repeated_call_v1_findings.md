# ASI重复调用与债务验证结果

2026-11-09，DRAFT_NONAUTHORITATIVE。历史eligible序列＋声明恢复情景，不能称为同址实测。

## 判断

本轮未支持拟验证的新意：在预先声明的offer范围内，逐次核算与联合核算给出同一连续承诺边界；h8与h16恢复能力升级也没有改变承诺边界。EDF与最大流全部一致。只有把最终恢复能力提前可用的弱静态基线出现乐观判断。这不证明重复调用问题普遍无意义，但本轮不能作为TSG新方法证据。

## 固定输入与结果

12个时间起点×2种事件间隔×2种期限×2种资源投运×5个offer水平=480实例；均无缺测。每次事件2h，offer为0/25/50/75/100%的历史h2、95%K，基准2.4216919MW向下量化为2.421MW。调用时逐小时还必须不超过实际量化eligible。恢复上限升级前K/4、后K/2、eta=1、原期限lag=4/12h均为机制假设，未加入checkpoint损失。

|比较结果|实例数|
|---|---:|
|实际eligible不足|16|
|联合时序可履约|352|
|eligible通过但联合恢复失败|112|
|每事件单独通过、联合失败|0|
|最终资源提前可用通过、联合时序失败|68|
|EDF与最大流不一致|0|

“最终资源提前可用”与真实时变资源在48/96组的扫描最大通过offer上有差异，但这不是两个真实阶段计划之间的差异。h8/h16配对的240个相同offer判断全部相同。

## 避免扫描掩盖差异的解析补充

从保存输入按全部任务子集Hall条件计算连续offer上界。每个事件债务为2×offer，对任务子集J，offer≤可用小时并集容量/(2×事件数)。最终上界还需取实际eligible与预先声明offer上限2.421MW的最小值。不能在得知结果后放大offer范围来寻找正例。

96组解析边界逐点符合全部扫描结果；在该范围内，单独与联合连续边界差异仍为0，h8/h16连续边界差异也为0。因此本轮阴性结论不是仅由25%扫描步长导致。

## 一个静态误判实例

origin=0，第二事件起点h4，期限lag=4，升级h8，offer=1.2105MW。第一次事件债务2.421MWh，允许补做h2–h5，其中h4/h5用于第二次调用，只有h2/h3可恢复，容量和为1.2105MWh。该单事件已不可行，后续事件共享争用并不是失败主因。精确子集证据保存在report.json。

## 适用边界与研究处置

K来自全样本历史产品，无外样本预测或95%保证；ASI序列为无干预观测，调用未反馈改变未来eligible。恢复路径独立于ASI任务状态，不是真实设备/网络扩建；只比较给定资源情景。两事件采用相同offer、相同时长，未覆盖所有到达/期限/响应合同结构。最大流是可分割单资源可行性参考，不证明现有完整q/r或网络模型的可行性。

本轮已足够说明：不能仅靠把文献eligible曲面加上示例恢复期限，就宣称形成新的阶段承诺方法。建议保留当前毕业论文的阶段履约评价证据；若坚持TSG方法定位，先完成与期限/恢复感知强基线的具体文献差异和真实合同/恢复数据论证，再投入新模型或大实验。不要继续只调同一小例参数追逐非零差距。

## 独立只读开发审查

审查未发现推翻上述有限结论的核心计算错误；单位、恢复窗口、原期限与比较任务口径一致。属于non-authoritative开发审查，不是official sealed review。

EDF一致性只针对真实时变路径的联合恢复子问题，不能写成EDF独立解释全部对照；有8行EDF恢复可行但最终chronological因即时eligible门失败。计数字段edf_disagreement未递增，证据实际来自每实例的assert与completed状态。报告actual_recovery_units应按契约解释为假设恢复余量，不能当实测。68个终态静态乐观实例在逐事件单独核验中也全部失败，故不归因于重复债务竞争。原始工件保持不变，解释更正记录于此。
