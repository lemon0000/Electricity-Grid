## 哪些是源码，哪些是缓存

| 文件或目录 | 用途与处理 |
|---|---|
| `tests/`及`test_*.py` | 测试源码，核对任务余额、期限、网络与持久化行为，需要保留。 |
| `.pytest_cache/` | pytest保存测试节点、上次失败等信息，可删除，下次测试会再生成。 |
| `.pytest-*/` | 显式指定的旧测试临时工作目录；本轮三个目录被Windows拒绝访问，未核实其内容。 |
| `__pycache__/`、`*.pyc` | Python编译缓存，可删除，导入时可能再生成。 |
| `.ruff_cache/` | 代码检查器缓存，可删除。 |
| `results/` | 实验输出、失败、检查点和审计证据，按绑定合同保留。 |
| `.git/` | 版本历史与本机发布核验记录，保留。删除工作区旧图不会抹掉Git中的旧版本。 |
| `.specstory/` | 本地对话历史，保留；它不是pytest或Python缓存。 |
| `.codex/`、`.claude/`、`.vscode/` | 本地代理或编辑器配置，保留。编辑器已折叠常见缓存目录。 |

## 已安装的科研skill

用户安装目录`D:/Codex/skills`与`%USERPROFILE%/.codex/skills`指向同一套文件，后者为Junction。该目录有13个顶层SKILL入口，其中9个直接面向科研，另有1个Nature共享包；`.system`还提供imagegen等5个系统技能。应用插件提供的PDF等技能另行加载。

| 科研skill | 适用任务 | 在当前项目中的使用记录 |
|---|---|---|
| `nature-figure` | 科研图、机制示意、AI插画组装与导出核查 | 最近这轮已使用SVG、PDF文字和碰撞审查脚本。 |
| `literature-review-workflow` | 文献检索、开放PDF、精读、证据表和综述 | 本轮清点未查到明确调用记录。 |
| `paper-novelty-design-v1` | 创新点、可证伪命题、贡献及审稿压力测试 | 本轮清点未查到明确调用记录。 |
| `citation-check-skill` | 核对引用、来源与图表事实 | 已有来源核查成果，但不能据此认定调用过此skill。 |
| `scientific-visualization` | 数据编码、单位、缺失、不确定性与可访问性 | 当前主要是概念插画；后续实验数据图适用。 |
| `scipilot-figure-skill` | 先剖析数据、选择图型，再制作科学数据图 | 与当前概念卡通不同，后续数据图可按需选择。 |
| `academic-figure-skill` | 期刊科研图与出版排版 | 与其他画图skill有重叠，未查到本轮明确调用。 |
| `arxiv-digest` | 每日arXiv `cs.RO`筛选与Zotero同步 | 默认面向机器人方向，当前任务未调用。 |
| `humanities-thesis` | 人文社科中文论文全流程 | 本轮清点未查到明确调用；其主要领域与当前项目不同。 |
| `nature-shared` | Nature系列参考共享包 | 已安装；不能仅凭安装证明具体参考文件已使用。 |

“未查到明确调用”只描述本轮核对的本地证据，不表示所有历史会话都从未用过。最近卡通的实际图像由`image_gen.imagegen`生成，PDF排版使用PDF技能；这些与安装了几个画图skill是不同层面。

## 按任务选择主流程

- 文献综述：`literature-review-workflow`；引用和来源复核：`citation-check-skill`。
- 研究定位、创新与贡献：`paper-novelty-design-v1`。
- 当前框架、卡通和机制图：`nature-figure`；生成插画时配合imagegen。
- 后续实验数据图：按数据和图型需求，选择`scientific-visualization`或`scipilot-figure-skill`。
- 模型正确性、冻结工件及正式研究审查：继续遵守[agent.md第7—9节](../../agent.md)，由实现、独立审查与证据核验完成。

技能是按任务加载的操作规范，不会因安装就自行执行。相近画图流程通常选择一个作为主流程；来源核查、创新判断和模型审查承担不同工作，需要在对应任务中使用。
