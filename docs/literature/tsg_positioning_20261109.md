# 面向 TSG 的研究定位核查

2026-11-09。定向文献核查及研究建议，不是系统综述、不构成优先权证明或正式科研结论。来源与阅读范围见 [证据表](tsg_positioning_20261109.csv)。截至本次检索，最近直接相关来源为 11 月 1 日的 temporal redispatch 预印本；11 月 3 日 query routing 为工作负荷映射旁证，仅核摘要。各 arXiv 来源不自动视为已发表 TSG 论文。

## 判断

当前“分阶段场景＋最小柔性比例＋三方法比较”的证据，尚不足以支撑有竞争力的 TSG 投稿。不是问题无意义，而是最近邻已覆盖期限调度、最小接入容量、容量扩展、建设时滞、可交付容量承诺及忽略服务约束导致的高估。新场景需要产生可迁移的技术结论。

值得进一步论证的核心问题：给定当前业务、已投运设备、网络状态和按剩余期限区分的任务债务，下一阶段允许承诺多少柔性或释放多少接入负荷，才能保持未来履约可行？这是候选研究问题，尚未证明有新颖性或完成算法。

## 最重要的最近邻

- [Cui 等，2026-10-16](https://arxiv.org/html/2610.22912v1)，§IV 与 §VI-C 已比较 grid-centric 与 QoS/频率安全约束下的接纳容量，并量化系统性高估。不能只以“加入业务约束发现高估”为主贡献。
- [Li 等，2026-11-01](https://arxiv.org/html/2611.02228v1)分离经济激励与物理移峰能力，明确物理限制产生无法靠激励消除的缺额。不能把“物理不足优化救不了”作为通用新发现。
- [Butt 等，2026-08-29](https://arxiv.org/pdf/2608.29359)已将任务期限与现场资源配置纳入最小接入容量规划。仅把最小容量改成最小比例不足以构成贡献。
- [Zhu 等，2026-10-09](https://arxiv.org/html/2610.13032v1)已考虑输电开工、建设时滞和任务空间迁移。三条进度的独特作用须来自它们与期限恢复状态的联系。
- [Kim 等](https://arxiv.org/html/2605.14714v1)把运行包络用于接入筛选；Discussion 明确假设包络完全履约。该假设提供具体研究切口，但不是证明所有既有文献都未解决内部履约问题。

## 建议技术主线

1. 明确承诺对象：固定接入点、给定设备/电网计划，输出阶段性的可兑现响应包络或可接入负荷边界；最小 f 为投影指标。
2. 状态必须保留债务的剩余期限分布，不能只保留总 MWh。小时运行状态与跨月投运状态分别建模；跨边界债务连续。
3. 区分固定策略执行与存在某个调度可行。先以小型离线 LP/时空流模型作可行性参考，再检查可执行因果策略；不给完美预见结果贴在线保证标签。
4. 若推导窗口容量判据，必须检查重叠任务对共享恢复容量的竞争；逐任务各自有足够余量不保证联合可行。不能将经典调度判据本身宣称为新定理。
5. 候选计划筛选或优化使用上述包络，检查它是否改变可接纳 MW、投运选择或真实履约风险。经济目标仅在成本数据可信时加入。

## TSG 贡献门槛（本次判断，不是期刊硬性清单）

- 一个超出新增索引/约束组合的技术对象：例如阶段与期限状态相关的可兑现边界，及适用条件明确的计算方法。
- 相比强基线有区别：保留期限与恢复的静态模型、标准滚动调度、离线参考；瞬时 MW 与固定余量仅作消融。
- 网络与业务均有依据；N-1 静态余量不能自动代表连续调度可行。按主张选择必要物理验证，不机械堆叠 SCUC/AC/频率模型。
- 多个未用于设计的路径和不确定性条件，完整报告无改善及失败区域。冻结策略进行留出检验。
- 可扩展性与可复现性；48 个合成固定策略场景是机制诊断，不是上述证据。

## 停止条件

如果加入阶段信息只重现普通时间变容量调度，且不改变承诺边界或计划选择，应收缩为应用评价；如果收益只来自削弱基线、已知未来、无依据成本或人为阈值，应停止该主张。暂不承诺 TSG 接收概率，不启动新实验。

TSG 官方范围包含 DR/DSM，且把单纯经济、定价、市场框架列为范围外示例。因而更适合以电网交互和可执行响应为中心，而不是单独的投资经济比较：[官方范围](https://ieee-pes.org/publications/transactions-on-smart-grid/)。
